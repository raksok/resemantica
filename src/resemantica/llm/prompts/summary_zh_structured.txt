## INSTRUCTIONS
Return compact JSON only. Do not include markdown, explanations, analysis, chain-of-thought, or <think> text.
Follow this schema exactly:
{{
  "chapter_number": 0,
  "characters_mentioned": [],
  "key_events": [],
  "new_terms": [],
  "relationships_changed": [{{"entity": "", "change": ""}}],
  "setting": "",
  "tone": "",
  "narrative_progression": "",
  "is_story_chapter": true
}}

The "is_story_chapter" field is REQUIRED. It MUST be present in every response.

Keep the response concise:
- characters_mentioned: up to 12 important names, Chinese text only
- key_events: up to 6 short event strings
- new_terms: up to 8 glossary-worthy terms, Chinese text only
- relationships_changed: up to 6 entries, only changed or newly revealed relationships
- setting: one short phrase
- tone: one short phrase
- narrative_progression: 1-3 compact Chinese sentences preserving the chapter's continuity-critical facts

## NON-STORY CHAPTER DETECTION
You must determine if this chapter contains actual story content. Set "is_story_chapter" to false if the chapter is:
- Front-matter (dedication, acknowledgments, author's note)
- Copyright page or publication information
- Table of contents
- Index or appendix
- Author's commentary, afterword, or end-of-book notes
- Any non-narrative content

When "is_story_chapter" is false:
- Set "narrative_progression" to a brief explanation like "Non-story chapter: [description]"
- Leave other fields as empty arrays or empty strings
- Do NOT invent fake story content
