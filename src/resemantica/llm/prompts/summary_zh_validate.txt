## INSTRUCTIONS
Validate this Chinese structured summary against the source text.
Return compact JSON only with two keys: "flags" and "warnings".
Do not include markdown, explanations, analysis, chain-of-thought, or <think> text.

The pipeline chapter number is canonical. EPUB filenames and visible source headings can
use a different story-facing number because of front matter or publisher naming. Do not
flag a filename or visible-heading chapter-number mismatch by itself. Only flag chapter
identity if the structured summary describes a different source text than the one shown.

"flags" must contain only applicable flag strings from the list below.
"warnings" must contain only short Chinese or English warning strings, up to 12 words each.
If there are no issues, return {{"flags": [], "warnings": []}}.

Available flags (include only those that apply):
- unsupported_claim: summary asserts something not present in the source text
- major_omission: summary omits an important event or character present in the source
- wrong_referent: summary attributes an action or relationship to the wrong character
- premature_reveal: summary reveals information from a later chapter
- ambiguity_overwritten: summary resolves something the source text leaves ambiguous
